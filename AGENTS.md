# UnityGameModules instructions

- Read README.md and the relevant maintained module before creating or changing a shared system.
- Follow the global instructions and relevant owners in `D:/Codex/UnityKnowledge/Docs/KNOWLEDGE_MAP.md`.
- This repository owns module discovery and the separation plan. Change runtime code in its maintained module source, using an isolated task worktree.
- Keep game mechanics, content, schemas, SDK wiring and consumer adapters in the game. Do not build a common package around one game's object names or rules.
- Update the current index or plan directly, with a short updated date. Do not add chat archives, source inventories, extraction reports or evidence appendices.
- Preserve required source ownership, licenses, public contracts and exact consumer dependency pins. A planned module is not an available release.
